# Пошаговые задания для Cline / Codex

## 00 — Запуск и проверка

Распаковать архив, запустить `npm install`, `npm run typecheck`, `npm run dev`, проверить desktop/mobile, затем `npm run build`. Убедиться, что `/admin` в production закрыт до внедрения Auth. Не делать commit/push без подтверждения.

## 01 — Редактура дизайна

Изменения строго в UI, без внедрения бэкенда: проверка 1920/1440/1024/768/390/375 px, работа меню, фильтров, галерей, форм, accessibility, фокус-состояний, производительности и `prefers-reduced-motion`.

## 02 — Правильный скролл-тур

Сейчас Hero — **2.5D переходы между 5 отдельными фотографиями одной концептуальной квартиры**. Полноценного физически непрерывного пролёта нет. Для кинематографичного непрерывного тура потребуется одно цельное исходное 3D-помещение со всеми комнатами и траекторией камеры либо качественный предрендеренный ролик с контролем кадров при прокрутке. Сохранять HTML заголовки и кнопку над видео. Не разрезать фотографии на полосы.

## 03 — Фотографии ещё трёх квартир

Пополнить отсутствующие галереи (Urban Loft, Airy Minimal, Modern Classic), подготовить светлые/тёмные варианты и согласованные ракурсы, добавить оптимизированные WebP и alt. Только после этого публиковать эти карточки.

## 04 — PostgreSQL + Prisma + Repositories

См. `docs/ADMIN-ARCHITECTURE.md`. Ввести миграции и seed. Проверять доступ с сервера. Не допускать показа DRAFT в публичном API.

## 05 — Auth / роли

Добавить вход, восстановление доступа, защищённые cookie, RBAC и аудит. Проверить запросы без сессии и с ролью VIEWER на запрет изменений.

## 06 — Projects CRUD / Media

Администратор создаёт/редактирует/публикует проекты и управляет фотографиями. Версионирование/валидация загрузок, превью и удаление файлов с референциальной целостностью.

## 07 — Leads / Review moderation

Реализовать POST endpoints на защищённом сервере, Zod validation, rate limiting, антиспам, consent version, уведомления и управление статусами. Юридическая проверка политики обязательна.

## 08 — SEO и production

Согласовать реальные реквизиты, перевести robots/noindex в index для публичных страниц после публикации, sitemap.xml, Open Graph, аналитика с согласием, error monitoring, тесты формы, экранов, SEO и деплой на Vercel.
