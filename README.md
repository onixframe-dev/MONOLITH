# MONOLITH · INTERIOR STUDIO

**Премиальный демонстрационный сайт студии дизайна квартир. Новый проект с нуля, без кода и дизайна PITA.**

Stack: Next.js 14 App Router + React 18 + TypeScript + GSAP ScrollTrigger + CSS + Lucide. Будущая модель данных: PostgreSQL + Prisma, Auth.js + RBAC. В проект включены подготовленные ранее WebP изображения.

## Быстрый старт (Windows)

1. Распакуйте архив и откройте `MONOLITH-STUDIO-NEXT` в VS Code.
2. Убедитесь в Node.js 20.9+.
3. Дважды нажмите `START_WINDOWS.bat` или выполните команды вручную:

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для TypeScript и production check:

```bash
npm run typecheck
npm run build
npm run start
```

Если интернет для npm недоступен, откройте `OPEN_PREVIEW.html` для автономного просмотра визуальной концепции главной страницы. Это **не** запуск Next.js приложения.

## Готовые маршруты

- `/` — длинная кинематографичная прокрутка по пяти комнатам, динамический текст, портфолио, услуги, этапы, контактная форма.
- `/proekty` — каталог 3 опубликованных концепций с фильтрами.
- `/proekty/city-evening`, `/proekty/soft-nordic`, `/proekty/night-contrast` — галереи и описание.
- `/uslugi`, `/o-studii`, `/etapy`, `/kontakty`, `/otzyvy` — дополнительные страницы.
- На главной есть интерактивный конфигуратор параметров квартиры: площадь, вид работ и стиль, без вымышленных тарифов.
- `/politika-konfidencialnosti`, `/soglasie-na-obrabotku`, `/cookies` — юридические **шаблоны для доработки**, а не опубликованные юридические гарантии.
- `/admin` и дочерние — только read-only каркас админки. **По умолчанию закрыт в production**, доступен локально (`npm run dev`).
- `GET /api/projects` — публичный JSON трёх опубликованных концепций.
- `POST /api/contact`, `POST /api/reviews` — честные `503`, пока нет backend.

## Почему не подключены реальные формы

Нет утверждённого оператора персональных данных, контактов и настроенной защищённой БД. Формы работают как **демонстрация интерфейса**, ничего не отправляют и не сохраняют. Текст на странице честно сообщает об этом. Отзывы не выдуманы. Стоимость, реальные адреса и фактические клиенты не выдуманы.

## Почему скролл-экскурсия не является настоящим 3D

Текущая прокрутка плавно переключает 5 фотосцен одного интерьерного концепта и меняет текст. Она не обеспечивает геометрически непрерывное движение камеры: отдельно созданные кадры не имеют общей гарантированной 3D-геометрии. Полный маршрут требует 3D-сцены или специально подготовленного видео. См. `docs/IMPLEMENTATION-STAGES.md`.

## Важная структура

```text
src/app/(site)          публичные страницы
src/app/(admin)/admin   read-only админ-интерфейс (позже Auth)
src/app/api             API-контракты и заглушки
src/components          независимые UI-компоненты
src/lib/projects.ts     единственный текущий источник данных проектов
src/lib/site.ts         настройки публичной навигации и услуг
src/types               доменные типы
prisma/schema.prisma    схема будущей базы (НЕ подключена)
public/images           оптимизированные WebP ассеты
docs                    план, безопасность и архитектура
```

## Состояние фотобиблиотеки

Использованы 14 уникальных AI-интерьерных кадров (и их WebP размеры) для 3 проектов. В `src/lib/projects.ts` заложено 6 проектов: 3 PUBLISHED и 3 DRAFT без полноразмерной галереи. Последние три не показываются посетителю и будут доступны к публикации после фотосъёмки/генерации качественной серии.

## Production-проверка

Отсутствие сборки здесь не означает, что она прошла: npm registry в среде подготовки был недоступен (`EAI_AGAIN`), поэтому зависимости не установились и production build **не был проверен**. Локально выполните указанные команды. До реальной публикации необходимо внедрить авторизацию админки, формы, контакты, юридические тексты и убрать `noindex` только после подтверждения контента.
